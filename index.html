Техникалық талаптар

Өнім қандай форматта болуы тиіс?

Өнім түріңізге сәйкес тақтаны таңдап, талаптармен танысыңыз.

🌐 Веб-жобалар

  • ✓ Интернет арқылы ашылатын тұрақты URL-сілтемесі болуы тиіс
  • ✓ localhost, 127.0.0.1 немесе тек қатысушының компьютерінде жұмыс істейтін нұсқалар қабылданбайды
  • ✓ Басқа компьютерден немесе мобильді құрылғыдан ашылуы тиіс

📱 Мобильді қосымшалар

  • ✓ Android қосымшалары орнатуға дайын .apk файлы түрінде ұсынылады
  • ✓ APK басқа Android құрылғысына орнатылып, жұмыс істеуі тиіс
  • ✓ Тек эмуляторда жұмыс істейтін жоба қабылданбайды

🖥 Компьютерлік бағдарламалар мен ойындар

  • ✓ .exe, installer немесе дайын build түрінде ұсынылады
  • ✓ Басқа компьютерге көшірілгеннен кейін іске қосылуы тиіс
  • ✓ Unity, Unreal, Visual Studio сияқты әзірлеу ортасын ашу талап етілмейді

🤖 Виртуалды ассистенттер мен интерактивті жүйелер

  • ✓ Тек мәтіндік жауаппен шектелмеуі тиіс
  • ✓ Визуалды интерфейс пен пайдаланушымен интерактивті әрекеттесу мүмкіндігі болуы тиіс
  • ✓ Қажет болса дауыс, анимация, 2D/3D аватар немесе басқа визуалды элементтер қолданылуы мүмкін

Сұрақ-жауап

Жиі қойылатын сұрақтар

Веб-қосымша, мобильді қосымша, білім беру платформасы, ойын, виртуалды ассистент, AI жүйесі, AR/VR/3D, интерактивті сервис немесе қазақ тілі мен мәдени мұраны насихаттайтын цифрлық платформа. Өнімнің жұмыс істейтіндігі міндетті.

Жоба жеке қатысушы немесе 2–5 адамнан тұратын команда атынан ұсынылуы мүмкін. Жас шектеуі қойылмайды.

Иә, ChatGPT, Gemini, Claude, GitHub Copilot және басқа AI құралдарын қолдануға рұқсат. Бірақ қатысушы жобаның қалай жұмыс істейтінін және AI қай бөлікте пайдаланылғанын түсіндіре алуы тиіс.

Жоқ. Веб-жобаларда тұрақты URL міндетті, APK басқа құрылғыға орнатылуы керек, EXE басқа компьютерде іске қосылуы керек. localhost, 127.0.0.1 немесе тек эмуляторда жұмыс істейтін жобалар қабылданбайды.

APK, EXE және басқа көлемді файлдарды Google Drive немесе басқа бұлттық сақтау сервисіне жүктеп, қарауға/жүктеп алуға ашық сілтеме арқылы ұсыныңыз.

Байқау 2026 жылғы 6 қарашада өткізіледі. Әр қатысушыға 5 минут таныстыру және 3 минут қазылар сұрағына жауап беру уақыты беріледі.

Жұмыс істемейтін, тек презентация/макет түріндегі, тек localhost режиміндегі, басқа тұлғаның жұмысын иемденген (плагиат) және қазақ тілін қолдану мақсаты анық көрінбейтін жобалар.
